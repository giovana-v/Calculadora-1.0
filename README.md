# Calculadora - V 1.0

Uma calculadora simples feita com HTML, CSS e JavaScript puro. Ela realiza as quatro operações básicas (soma, subtração, multiplicação e divisão), com visor que mostra a expressão digitada e o resultado.

🔗 **Acesse o site:** https://giovana-v.github.io/Calculadora-1.0/

Este foi o meu **primeiro projeto** com HTML, CSS e JavaScript, desenvolvido durante o curso **Técnico em Informática** da **ETEC de Hortolândia**.

## Funcionalidades

- Operações básicas: `+`, `-`, `*`, `/`
- Visor com a expressão em andamento e o resultado
- Números decimais (ponto)
- `Ac` para limpar tudo
- `⌫` para apagar o último caractere

## Tecnologias

- **HTML** — estrutura da página
- **CSS** — estilização e layout da calculadora
- **JavaScript** — lógica das operações e interação com os botões

## Como executar

Não é necessário instalar nada. Basta clonar ou baixar o projeto e abrir o arquivo `index.html` no navegador:

```bash
git clone https://github.com/giovana-v/Calculadora-1.0.git
cd Calculadora-1.0
```

Depois é só abrir o `index.html` com um duplo clique ou direto no navegador.
